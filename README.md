# МЕТАЛІСТ ШТУТТГАРТ — Telegram Mini App

Додаток клубу **Metalist Stuttgart** відкривається всередині Telegram: тактична дошка, тренування, склад, календар, матчі, щоденник і аналітика. Роль (тренер / гравець / гість) береться з акаунта Telegram.

Окремого сервера немає. GitHub публікує програму, Telegram відкриває її як Mini App. Склад, подарунки і фото передаються лише файлом JSON між пристроями.

## Запуск

Потрібен Node.js 18 або новіший.

```bash
npm run dev
```

Відкрийте [http://127.0.0.1:43127](http://127.0.0.1:43127).

Інший порт: `DEV_PORT=44000 npm run dev`.

## Що є в інтерфейсі

- **Головна** — найближче тренування, склад, швидкі дії
- **Тренування** — план, вправи, відвідуваність
- **Схеми** — фази гри (побудова, пресинг, блок) і вихід на дошку
- **Гравці** — картки кольору акаунта, подарунки від тренера, чат команди
- **Дошка** — фішки, малювання, лавка, таймер. Відкривається з емблеми в шапці
- **Аналітика** — графіки відвідуваності, RPE, навантаження, амплуа і статусів
- **Календар, матчі, щоденник, налаштування**

Перший запуск підставляє демо-склад і вправи. Свої дані можна вивантажити кнопкою «Експорт JSON» і завантажити назад у налаштуваннях.

## Спільні дані клубу

Дані не лежать у репозиторії. Тренер експортує JSON у налаштуваннях і імпортує цей файл на іншому пристрої. Анкета гравця переносить його вибір подарунка біля імені. Явку ставить тренер.

## Перевірки

```bash
npm test
npm run build
```

`npm test` ганяє модульні тести (математика дошки, координати, HMAC initData, ролі). `npm run build` копіює статику в `dist/`. Перегляд збірки: `npm run preview` (той самий порт).

## Клубний бот

Mini App у Telegram працює без цього кроку. Окремий бот потрібен лише якщо треба слати в групу опитування відвідування і план тренування. Токен тоді лишається в `.env`, кроки — у [BOT_SETUP.md](BOT_SETUP.md).

## Запуск у Telegram через GitHub

1. Створіть репозиторій і запуште гілку `main`. У цьому новому проєкті це кнопка Create repo.
2. У репозиторії: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` на кожен push збирає `dist/` і публікує адресу для Telegram.
4. Після зеленого запуску скопіюйте адресу вигляду `https://<ім’я>.github.io/<репозиторій>/`.
5. У @BotFather відкрийте бота → Bot Settings → Configure Mini App (або Menu Button) і вставте цю адресу.
6. У Telegram відкрийте бота і натисніть кнопку меню. Склад з’явиться після імпорту клубного JSON.

Локальна перевірка файлів: `npm run dev`, порт `43127`. У телефон це не підставляється. У Telegram потрапляє лише адреса з кроку 4.
